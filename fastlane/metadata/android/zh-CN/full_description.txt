Himitsu（秘密）是一款注重隐私、免费开源的 AI 角色扮演客户端，并把在设备上运行模型作为一等功能。它是 Kafuu Neko 的 RPClient 的分支（fork）。

隐私优先
- 聊天、角色、世界书、设置和 API 密钥都保存在加密的 SQLCipher 数据库中，其密钥由 Android Keystore 保护。可选的恢复码可在该密钥丢失时帮你找回数据。
- 头像、聊天图片和草稿使用 AES-256-GCM 加密。
- 支持生物识别或设备 PIN、图案、密码的应用锁。锁定时会隐藏最近任务中的预览，也可以禁止截屏。
- 没有分析统计、遥测、崩溃上报、广告，也不使用 Google 服务。Himitsu 只会连接你配置的 AI 服务，以及在你要求时连接 Hugging Face 下载模型。
- Android 备份和设备间迁移不会导出任何内容。

设备端模型
- 使用从源码构建的 llama.cpp 离线运行 GGUF 模型。
- 在受支持的手机上可选用 OpenCL GPU 加速。
- 可导入任意 GGUF 文件，或从 Hugging Face 下载推荐模型。只有在你点击按钮时才会下载，并通过 SHA-256 校验。

角色扮演功能（继承自 RPClient）
- 导入兼容 SillyTavern 的角色卡（JSON 和 PNG）、世界书和 Regex 脚本。角色卡内嵌的 Regex 脚本只有在你授权后才会运行。
- 单人聊天、群聊，以及用于多章节故事的 Story Studio。
- 摘要记忆、提示词预设，以及能准确显示发送内容的 Prompt Inspector。
- 以 SillyTavern .jsonl 格式导入和导出聊天记录。
- 可连接 OpenAI 兼容 API、Gemini、Claude、DeepSeek、OpenRouter、xAI 或你自己的服务器。

可选伪装
Himitsu 可以更换图标和名称，伪装成真正可用的计算器、指南针或单位换算器。在伪装应用中输入秘密代码或手势会打开系统身份验证界面，绝不会跳过应用锁。伪装默认关闭，并且需要开启应用锁和屏幕锁。
伪装只是遮掩，不是安全措施。Android 设置（应用、通知、电池、存储）仍会显示 Himitsu，包名、应用商店历史、系统指纹或 PIN 验证界面、部分通知的标题以及 adb 等工具也会暴露它。开启前，应用会说明这些限制。

须知
- Himitsu 不内置任何 AI 服务。请使用设备端模型，或配置你自己的服务商和 API 密钥；请求只会发送给该服务商，并受其隐私政策约束。
- 模型生成的内容取决于你选择的模型和服务商。
- 需要 Android 8.0 或更高版本的 64 位设备。

Himitsu 是采用 GPL-3.0-or-later 许可证的自由软件，与 SillyTavern、OpenAI、Google、Anthropic、DeepSeek、OpenRouter、xAI 和 Hugging Face 均无关联。
