Himitsu（秘密）是一款注重隱私、免費開源的 AI 角色扮演用戶端，並把在裝置上執行模型當作一等功能。它是 Kafuu Neko 的 RPClient 的分支（fork）。

隱私優先
- 聊天、角色、世界書、設定和 API 金鑰都儲存在加密的 SQLCipher 資料庫中，其金鑰由 Android Keystore 保護。可選的復原碼可在該金鑰遺失時幫你找回資料。
- 頭像、聊天圖片和草稿使用 AES-256-GCM 加密。
- 支援生物辨識或裝置 PIN、圖案、密碼的應用程式鎖。鎖定時會隱藏最近使用畫面中的預覽，也可以禁止截圖。
- 沒有分析統計、遙測、當機回報、廣告，也不使用 Google 服務。Himitsu 只會連線到你設定的 AI 服務，以及在你要求時連線到 Hugging Face 下載模型。
- Android 備份和裝置間轉移不會匯出任何內容。

裝置端模型
- 使用從原始碼建置的 llama.cpp 離線執行 GGUF 模型。
- 在支援的手機上可選用 OpenCL GPU 加速。
- 可匯入任意 GGUF 檔案，或從 Hugging Face 下載推薦模型。只有在你點按按鈕時才會下載，並以 SHA-256 驗證。

角色扮演功能（承襲自 RPClient）
- 匯入相容 SillyTavern 的角色卡（JSON 和 PNG）、世界書和 Regex 指令碼。角色卡內嵌的 Regex 指令碼只有在你授權後才會執行。
- 一對一聊天、群組聊天，以及用於多章節故事的 Story Studio。
- 摘要記憶、提示詞預設，以及能準確顯示傳送內容的 Prompt Inspector。
- 以 SillyTavern .jsonl 格式匯入和匯出聊天記錄。
- 可連線到 OpenAI 相容 API、Gemini、Claude、DeepSeek、OpenRouter、xAI 或你自己的伺服器。

可選偽裝
Himitsu 可以更換圖示和名稱，偽裝成真正能用的計算機、指南針或單位換算器。在偽裝應用程式中輸入祕密代碼或手勢會開啟系統身分驗證畫面，絕不會略過應用程式鎖。偽裝預設關閉，並且需要開啟應用程式鎖和螢幕鎖定。
偽裝只是遮掩，不是安全措施。Android 設定（應用程式、通知、電池、儲存空間）仍會顯示 Himitsu，套件名稱、應用程式商店記錄、系統指紋或 PIN 驗證畫面、部分通知的標題以及 adb 等工具也會洩露它。開啟前，應用程式會說明這些限制。

須知
- Himitsu 不內建任何 AI 服務。請使用裝置端模型，或設定你自己的服務供應商和 API 金鑰；請求只會傳送給該供應商，並受其隱私權政策約束。
- 模型產生的內容取決於你選擇的模型和服務供應商。
- 需要 Android 8.0 或更新版本的 64 位元裝置。
