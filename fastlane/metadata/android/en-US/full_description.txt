Himitsu (秘密, "secret") is a free and open source AI role-play client built for privacy, with on-device models as a first-class option. It is a fork of RPClient by Kafuu Neko.

PRIVACY FIRST
- Chats, characters, lorebooks, settings and API keys are stored in encrypted SQLCipher databases, with keys protected by the Android Keystore. An optional recovery code lets you get your data back if that key is ever lost.
- Avatars, chat images and drafts are encrypted with AES-256-GCM.
- App lock with biometrics or your device PIN, pattern or password. Recents previews are hidden while the lock is on, and screenshots can be blocked.
- No analytics, no telemetry, no crash reporting, no ads, no Google services. Himitsu only connects to the AI service you configure and, when you ask for it, to Hugging Face to download a model.
- Android backups and device transfers export nothing.

ON-DEVICE MODELS
- Run GGUF models offline with llama.cpp, built from source.
- Optional GPU acceleration through OpenCL on supported phones.
- Import any GGUF file, or download a suggested model from Hugging Face. Downloads start only when you tap the button and are checked with SHA-256.

ROLE-PLAY FEATURES (from RPClient)
- Import character cards (JSON and PNG), lorebooks and Regex scripts compatible with SillyTavern. Embedded Regex scripts run only after you authorize them.
- One-on-one and group chats, and Story Studio for multi-chapter stories.
- Summary memory, prompt presets and a Prompt Inspector that shows exactly what is sent.
- Import and export chats as SillyTavern .jsonl.
- Connect to OpenAI-compatible APIs, Gemini, Claude, DeepSeek, OpenRouter, xAI or your own server.

OPTIONAL DISGUISE
Himitsu can change its icon and name to look like a working calculator, compass or unit converter. A secret code or gesture in the decoy opens the system authentication prompt; it never skips the app lock. Disguise is off by default and needs the app lock and a screen lock.
Disguise is discretion, not security. Android's Settings (Apps, notifications, battery, storage) still show Himitsu, as do the package name, your app store's history, the system fingerprint or PIN prompt, the header of some notifications and tools such as adb. The app explains these limits before you turn it on.

GOOD TO KNOW
- Himitsu does not include an AI service. Use an on-device model, or configure your own provider and API key; requests then go only to that provider, under its own privacy policy.
- What a model generates depends on the model and provider you choose.
- Requires Android 8.0 or later on a 64-bit device.
